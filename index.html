STL Heightmap

Turn an STL into a grayscale PNG heightmap for laser depth engraving (LightBurn 3D Sliced) or 2.5D CNC carving. Everything runs in your browser. Nothing is uploaded.

Lifts the lowest point of the model above the black background.
16-bit gives 65,536 height steps instead of 256, so smoother carves where your software supports it.
Carve away: black background, the model stands up in relief. Leave: white background, only the model is engraved.
Drop an STL here or click to choose a file. Binary and ASCII STL both work.
Download PNG
  1. Model the part in mm and export STL. The PNG carries its real size, so it imports into LightBurn at the model's width and height.
  2. Leave Invert off. LightBurn engraves dark areas deepest and skips pure white, so the top of the model (white) stays untouched.
  3. Pick 16-bit if you will run more than 256 passes (needs LightBurn 2.1 or newer).
  4. In LightBurn: Import the PNG, open the layer's Cut Settings, set Image Mode to 3D Sliced, then set Number of Passes for the total depth. Check Preview before burning.
3D Sliced is only offered for galvo lasers. See the LightBurn 3D Sliced guide.
